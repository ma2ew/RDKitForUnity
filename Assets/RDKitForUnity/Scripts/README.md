# RDKitForUnity Scripts Folder

This folder contains the vast majority of functionality in RDKitForUnity. For now, the scripts are separated into two folders:
* **ECS**: This contains molecule generation and parsing functionality. This is currently inaccurately labelled as ECS, as at the time of its creation.
* **Monobehavior**: This contains materials for manipulating the scene camera and a test script for RDKitForUnity itself. While currently labelled accurately in terms of the type of script it contains, this will be relabeled in the future as it is misleading in terms of the nature of the script.
